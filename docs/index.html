About / How to use

Purpose

This browser demo is a simplified Social Force Model-inspired pedestrian simulation. It uses desired movement towards the nearest exit, repulsive pedestrian interactions and boundary repulsion. It represents a hypothetical environment, not the actual street map of Kandy.

How to use

  • Choose the initial number of pedestrians.
  • Select one, two or three exit openings.
  • Adjust the walking-speed multiplier.
  • Press Start to run, Pause to stop temporarily, or Reset to restore the selected settings.

Reading the outputs

T95 is the time when at least 95% of pedestrians have exited. Clearance time is recorded when every pedestrian has exited. Peak local density is the highest number of pedestrians per square metre recorded in any 2 m × 2 m cell during the run.

Model settings and limitations

The environment is 40 m × 20 m. The model uses a 0.05 s time step, 0.5 s relaxation time, 2.0 m/s maximum speed and 4.0 m/s² maximum acceleration. Pedestrian radii are 0.3 m and initial placement uses a 0.65 m minimum separation. The model does not include real street geometry, measured attendance, group behaviour, vehicles or emergency responses.

Notebook reference case

The default 100-pedestrian, one-exit, 1.00× speed case uses the same fixed initial positions and desired speeds as the notebook's seed-42 baseline. The comparison panel checks T95, clearance time and peak density against the notebook output.
